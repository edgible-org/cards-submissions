# Submit an Edgible card

This is where anyone can submit a card for the [Edgible cards catalog](https://cards.edgible.org), or ask for a card to be tested again.

- **Add a card:** open a pull request with your card's folder. Checks run here on GitHub's own runners.
- **After review**, a card that passes is tested on Edgible's machines and, if it works, joins the official catalog in [edgible-org/cards](https://github.com/edgible-org/cards).

How to make a card, and the full guide, will be here soon. Until then, see [cards.edgible.org](https://cards.edgible.org).
