# Submit an Edgible card

This is where anyone submits a card to the [Edgible cards catalog](https://cards.edgible.org), asks for one, or asks for a card to be tested again. The official cards are in [edgible-org/cards](https://github.com/edgible-org/cards).

- **Add or fix a card:** open a pull request here with one card folder. [CONTRIBUTING.md](CONTRIBUTING.md) has the steps; [Add your app](ADD-YOUR-APP.md) is the short way for an app you wrote yourself.
- **Ask for a card:** open an issue from the app card or pattern card template.
- **Ask for a retest:** open the **Retest a card** issue form. It tests an official card again on Edgible's machines.

A pull request here is checked on GitHub's own machines. When a maintainer has read it, they promote it: it is tested on Edgible's devices and, if it passes, joins the catalog. The pull request is then closed with a link to the card's page.

Security problems go to [SECURITY.md](https://github.com/edgible-org/cards/blob/main/SECURITY.md), not to an issue. Everything here is under the [MIT License](LICENSE).
